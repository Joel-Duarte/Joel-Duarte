## 🚀 Flagship Projects

### 🧠 [Job Tracker — AI-Powered Career Hub & Orchestration Engine](https://github.com/Joel-Duarte/job-tracker)
> **Full-stack, local-first platform to automate job intake, evaluate candidate-job fit, and manage interview pipelines with strict data sovereignty.**

<p>
  <a href="https://joel-duarte.github.io/job-tracker/?ref=github"><img src="https://img.shields.io/badge/Live%20Demo-Visit%20Platform-38BDF8?style=flat-square&logo=safari&logoColor=white" alt="Live Demo" /></a>
  <a href="https://github.com/Joel-Duarte/job-tracker"><img src="https://img.shields.io/badge/Repository-Joel--Duarte%2Fjob--tracker-181717?style=flat-square&logo=github&logoColor=white" alt="Repo" /></a>
</p>

- **Architecture & Local-First AI**: Engineered a modular LLM orchestration layer prioritizing local open-source models (via LM Studio / Ollama) for zero-leakage data privacy, while providing cloud API fallback.
- **Workflow State Machines**: Implemented **LangGraph** deterministic state graphs and **PostgreSQL (`pgvector`)** semantic search for automated CV anonymization, skill gap analysis, fit scoring, and tailored cover letter generation.
- **Data Ingestion Pipeline**: Developed stealth job data scrapers (Camofox) and background recruitment email processors to automatically build structured timeline views.
- **Tech Stack**: `Vue 3` • `FastAPI` • `PostgreSQL / pgvector` • `LangGraph` • `Camofox` • `LM Studio`

### 📡 [SafeBaige — Proactive mmWave Radar Safety System](https://github.com/Joel-Duarte/SafeBaige)
> **Embedded real-time sensor acquisition and collision prevention module for micromobility safety.**

<p>
  <a href="https://github.com/Joel-Duarte/SafeBaige"><img src="https://img.shields.io/badge/Repository-Joel--Duarte%2FSafeBaige-181717?style=flat-square&logo=github&logoColor=white" alt="Repo" /></a>
</p>

- **Hardware & Protocol Integration**: Interfaced an **ESP32** microcontroller with **mmWave radar sensors** over UART / I²C for real-time spatial telemetry.
- **Real-Time Signal Processing**: Built low-latency spatial event detection algorithms in C++ to identify approaching vehicles, calculate closing velocities, and trigger proactive safety warnings.
- **Tech Stack**: `C++` • `ESP32` • `mmWave Radar` • `UART / I²C` • `Edge Computing`

## 🔬 Systems Internals & Protocol Deep Dives

Exploring low-level mechanics, custom protocols, and data structures from first principles:

- 🦀 **[Rusdis](https://github.com/Joel-Duarte/rusdis)**: Barebones Redis-compatible in-memory server built in **Rust** to study custom TCP socket protocol parsing, command dispatching, and low-overhead network concurrency.
- 🦫 **[GoGeit](https://github.com/Joel-Duarte/GoGeit)**: Distributed version control engine implemented in **Go** exploring Git internals, Directed Acyclic Graph (DAG) object stores, tree hashing, and content addressability.
